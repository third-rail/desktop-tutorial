# Desktop File Organization

Organized folder structure for managing desktop files.

## Folder Structure

```
Documents/
  Work/       - Work-related documents
  Personal/   - Personal documents
  Finance/    - Financial records, invoices, receipts
Images/
  Photos/     - Personal photos
  Screenshots/- Screen captures
Videos/       - Video files
Music/        - Audio and music files
Scripts/      - Utility scripts and automation
Projects/     - Project-specific files
Archives/     - Older files for long-term storage
```
